Des chatons équilibrés, élevés avec soin au cœur de notre foyer.

Chaque candidature est enregistrée dans notre base Supabase avec un code de suivi unique. Conservez bien votre code pour consulter votre dossier sur le site à tout moment.

Étape 1

Candidature & Code de suivi

Après validation de votre candidature, copiez votre code de suivi (ex. LPF-XXXX) : il est indispensable pour retrouver vos informations sur le site année après année.

Étape 2

Validation & Acompte

Dès validation de votre dossier et règlement de l'acompte (minimum 100 €), votre statut évolue dans la base de données.

Étape 3

Confirmation & Livraison

Une fois le dossier confirmé et payé, le bon de livraison complet (compagnie, livreur, client, références) et vos documents s'ouvrent dans votre suivi.

Nos chatons

La grande majorité de nos chatons sont entre 150 € et 300 € (nos meilleures sélections autour de 220 €–260 €), avec 4 lignées à 600 €–1 200 €. Acompte minimum : 100 €.
